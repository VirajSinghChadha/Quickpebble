↗Screen mode

Your words. A helping hand.

Describe a task and the AI operates your mouse and keyboard step by step. Routine steps run automatically. Risky or important actions ask first with numbered choices: press 1, 2, or 3. It double-checks before submitting. Move your mouse into a screen corner to stop. Requires a free Gemini API key and Python 3.

GOOD QUESTIONS

A few things to know.

Is it free?＋

Free during the beta.

Why do I need an access key?＋

We’re letting people in gradually while we test. Ask the developers for a beta access key.

Is my API key safe?＋

It’s stored encrypted on your account and never shown to anyone else.

What does Screen mode send?＋

Screenshots to Google Gemini at every step, only while you use Screen mode. You can stop it any time.

Which systems are supported?＋

Mac with Apple silicon or Intel, and Windows 10/11 (64-bit). Screen mode also requires Python 3 and a Gemini API key.

Why the security warning the first time?＋

Quick Pebble is not yet signed with a paid developer certificate. Follow the installation guides linked above.
