Installing Quick Pebble on Windows

It takes about a minute, and you only do it once.

Why will Windows show a warning? Quick Pebble is free and open source, but it isn't signed with a paid code-signing certificate yet. Windows SmartScreen therefore asks you to confirm that you trust it. This is normal for apps from independent developers, and you stay in control: nothing runs until you say so.

1 · Run the installer

1

Double-click the installer

Double-click Quick.Pebble_preview_x64-setup.exe.

What you'll see

Windows protected your PC
Microsoft Defender SmartScreen prevented an unrecognized app from starting.

2

Click “More info”

It's the small link under the message.

3

Click “Run anyway”

App: Quick.Pebble_preview_x64-setup.exeRun anyway

Then follow the installer. It installs just for you (no administrator password) and adds a Start menu entry. You only do this once.

My browser blocked the download

Open the browser's downloads list, click the ⋯ next to the file, choose Keep, then Keep anyway.

2 · Using Screen mode (optional)

The Screen assistant mode is the only part that needs extra setup: Python 3, a few packages, and a free Gemini key (Settings → AI). One time only:

  1. Install Python 3 from python.org. Tick “Add python.exe to PATH” on the first screen.
  2. In Quick Pebble choose Screen and send any task. If packages are missing, the message shows the exact command to run. It looks like:
python -m pip install -r "C:\Users\YOU\AppData\Local\Quick Pebble\agent\requirements.txt"

Paste it into Command Prompt or PowerShell. Skip this if you won't use Screen mode. Everything else works without it.

Is it safe? Quick Pebble is open source (MIT); every line is public at github.com/VirajSinghChadha/Quickpebble. Only download it from there. Your saved passwords are encrypted with a master password that only you know.
